**Digital Applications: Group Application Pitch**

This project was completed as part of the Digital Applications module. It involved working collaboratively on a group presentation pitching an application idea.

The aim was to present an application concept and communicate its purpose and proposed value to an audience.

1. Group PowerPoint presentation

2\. Application concept development

3\. Communication of ideas through presentation slides



**Skills Demonstrated**



1. Teamwork and collaboration

2\. Communication and presentation skills

3\. Organisation and planning

Developing and explaining ideas

4\. Contributing to a collaborative academic project
