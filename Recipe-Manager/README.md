**Recipe Manager**



**Overview**



The Recipe Manager is a Python application developed during my foundation year. It allows users to manage recipes, plan meals for the week, and generate shopping lists based on their selected meals.



The project helped me develop my Python programming skills and understand how data can be stored and retrieved using files.



**Features**



1. **Add Recipes:** Enter new recipes, including their names, ingredients, and preparation steps.



**2. Search Recipes:** Search for recipes by name.



**3. Weekly Meal Planner:** Assign recipes to specific days of the week.



**4. View Meal Plan:** Display the planned meals for the week.



**5. Generate Shopping List:** Create a shopping list using ingredients from the planned meals.



**6. File Handling:** Store recipe information in a CSV file and save meal plans and shopping lists in text files.



**Technologies Used**



Python

CSV files

Text file handling



**How to Run**



1. Make sure Python is installed on your computer.

2\. Download or clone this repository.

3\. Ensure recipe\_manager.py and recipes.csv are in the same folder.



4\. Run the program using:



python recipe\_manager.py

5\. Follow the instructions displayed in the terminal to use the menu.
